QuickPin

Écran de connexion par profils avec code PIN, pensé pour la TV. Les PIN sont hachés côté serveur (PBKDF2) et ne sont jamais stockés en clair.

Exemple : « Qui est-ce ? »
Si vous changez la longueur, ressaisissez le PIN de chaque profil.
Nécessite que le serveur puisse écrire dans le dossier web (voir README pour Docker). L'app Samsung/Tizen embarque sa propre copie du client web : voir le dossier tizen/ du dépôt pour la TV.

Profils affichés

Jusqu'à 6 profils. Laissez le champ PIN vide pour conserver un PIN déjà défini.
